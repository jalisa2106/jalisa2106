Building AutoNidhi: a role-secured auto finance platform

During my internship at Lyrcon Solutions I engineered full-stack features for AutoNidhi — an auto finance and insurance management platform — from role-based access control to a multi-stage approval pipeline and real-time notifications.

01 / WHAT I BUILT

Four responsibilities, end to end

Each feature was delivered across the stack — database, API, and interface — so it could be used by real people in real roles.

🔐

Role-based access

RBAC across three separate portals — Admin, Accountant and Customer — enforced on the API, not just hidden in the UI.

🧭

Pipeline workflow

A multi-stage pipeline where records move only through permitted, validated state transitions.

🗃️

Soft-delete safety

Deletions are reversible by design, protecting financial records from accidental data loss.

🔔

Real-time notifications

Users are alerted as their records change stage, without refreshing or polling by hand.

02 / ARCHITECTURE

One API, three portals, one source of truth

A Vite + React (TypeScript) front end serves each role its own portal. Every request carries a JWT that the FastAPI backend verifies and checks against the caller’s role before touching Neon PostgreSQL.

Permission checks live in the backend so a customer cannot reach admin behaviour by editing the front end.
